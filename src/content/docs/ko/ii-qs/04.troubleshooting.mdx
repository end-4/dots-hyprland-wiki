# 일반적인 문제 해결

## 시스템 패키지 업그레이드 후 의존성 손상
Arch Linux를 예로 들면, `sudo pacman -Syu`를 실행하여 시스템 패키지를 업그레이드하면 illogical-impulse의 로컬 빌드 패키지들은 자동으로 업그레이드되지 않습니다.

다음 명령어를 실행하여 의존성을 재설치하세요:
```sh
git stash && git pull  # Git 리포지토리 업그레이드
./setup install-deps
```

## Quickshell이 실행되지 않음 (상단 바 없음)

먼저 터미널에서 아래 명령을 실행하여 로그를 확인하세요:
```bash
pkill qs; qs -c ii
```
로그를 읽어보세요. 대부분의 관련된 오류 메시지는 맨 아래쪽에 위치합니다. 아래 케이스들을 참고하세요.

### 흔한 오류들

#### 모듈 "Quickshell.SOME_MODULE"이 설치되어 있지 않음

로그 예시:
```sh
  ERROR:   caused by @services/PolkitService.qml[6:1]: module "Quickshell.Services.Polkit" is not installed
  WARN: QThreadStorage: entry 1 destroyed before end of thread 0x7f4e91a18830
```
**해결 방법**: 다른 항목은 건너뛰고 Quickshell 설치 단계만 선택하여 설치 스크립트를 다시 실행함으로써 Quickshell을 업데이트하세요.

#### 모듈 "qs.modules.common.widgets.shapes"가 설치되어 있지 않음

로그 예시:
```sh
  ERROR:   caused by @modules/common/widgets/MaterialShape.qml[1:1]: module "qs.modules.common.widgets.shapes" is not installed
```
**해결 방법**: 서브모듈(submodule)이 제대로 클론되지 않은 경우입니다.
- 설치 스크립트 사용자: Git 서브모듈을 업데이트하라는 단계를 건너뛰지 마세요.
- 수동 설치 사용자: 
  - 리포지토리를 클론할 때 반드시 `--recurse-submodules` 플래그를 사용해야 합니다. 단순히 다운로드 버튼을 누르는 것으로는 작동하지 않습니다.
  - 이미 클론된 리포지토리라면 `git submodule update --init --recursive` 명령을 실행하세요.

## Python 가상 환경

환경 변수 `$ILLOGICAL_IMPULSE_VIRTUAL_ENV`가 올바르게 설정되어 있어야 Quickshell 설정의 일부 기능이 작동합니다. 기본 제공되는 설정 파일 `~/.config/hypr/hyprland/env.lua`(`~/.config/hypr/hyprland.lua`에 의해 로드됨)에 해당 환경 변수가 이미 포함되어 있습니다.

만약 환경 변수가 빠져 있다면, Hyprland 설정에 다음 라인을 추가하고 재시작하세요:
```ini
hl.env("ILLOGICAL_IMPULSE_VIRTUAL_ENV", home_dir .. "/.local/state/quickshell/.venv")```

`./diagnose`를 실행하여 값을 다시 확인할 수 있습니다.

정상 출력 예시:
```
[===diagnose===] declare -p ILLOGICAL_IMPULSE_VIRTUAL_ENV
declare -x ILLOGICAL_IMPULSE_VIRTUAL_ENV="/home/user/.local/state/quickshell/.venv"
[---SUCCESS---]
```
여기서 `user`는 사용자의 계정 이름입니다.

## 최소한 한 번은 시도해 볼 것들
- Hyprland를 재시작하거나 시스템을 부팅하세요. 환경 변수 변경 사항을 적용하는 데 필요합니다.
- `git pull`을 실행한 다음 `./setup install`을 다시 실행하여 모든 것이 올바르게 설치되었는지 확인하세요. 스크립트는 멱등성을 가지므로 확인이나 업데이트를 위해 언제든 자유롭게 실행할 수 있습니다.

# 흔한 기타 문제들
## 테마가 올바르게 보이지 않음

`Super+Ctrl+T`를 누르고 프롬프트 창에서 이미지를 선택하여 배경화면을 변경해 보세요. 그래도 작동하지 않는다면 터미널에서 `~/.config/quickshell/ii/scripts/switchwall.sh`를 실행하여 동일한 과정을 진행한 후 로그를 확인해 직접 문제를 찾아보거나 이슈/디스커션에 제출하세요.

## 도크/개요에 일부 애플리케이션의 아이콘이 표시되지 않음

기술적으로 모든 아이콘을 완벽하게 맞추는 것은 불가능합니다. 아이콘은 각 앱의 클래스(class) 이름으로 추정되는데, 이 이름이 항상 아이콘 이름과 일치하지는 않기 때문입니다.

가능한 해결 방법:
### GTK 앱: `gsettings`를 사용해 아이콘 테마 설정

기본 아이콘 패키지에 해당 앱의 아이콘이 없을 수 있습니다. 이 경우 다른 테마로 변경할 수 있습니다.

예를 들어 [Papirus](https://github.com/PapirusDevelopmentTeam/papirus-icon-theme)를 사용할 수 있습니다.
@end-4의 개인적 취향으로 기본 적용되지는 않았으나, 앱 지원 범위가 매우 뛰어납니다.

```sh
gsettings set org.gnome.desktop.interface icon-theme Papirus
```

물론 먼저 패키지를 설치해야 합니다. Arch Linux의 경우 `sudo pacman -S papirus-icon-theme`를 사용하세요.

### Qt 앱: kde-material-you-colors 설정 수정

`~/.config/kde-material-you-colors/config.conf` 파일을 엽니다.
아래 라인을 찾아 원하는 설정으로 수정하세요:
```ini
# ...
iconslight = breeze-plus
# ...
iconsdark = breeze-plus-dark
```

## 음악 제어 위젯이 나타나지 않음

> 참고: [end-4/dots-hyprland#168](https://github.com/end-4/dots-hyprland/issues/168) (주의: 이전 AGS 버전 관련 이슈입니다)

- 미디어 플레이어가 MPRIS를 지원하는지 확인하세요 (목록 참고: [MPRIS - Arch Wiki](https://wiki.archlinux.org/title/MPRIS))
- 브라우저인 경우 Plasma Integration 확장 프로그램을 설치하세요: 
  - [Firefox용](https://addons.mozilla.org/en-US/firefox/addon/plasma-integration/)
  - [Chromium용](https://chrome.google.com/webstore/detail/plasma-integration/cimiefiiaegbelhefglklhhakcgmhkai)

`plasma-browser-integration` 패키지가 설치되어 있는지 확인하세요 (Arch Linux 외 배포판은 해당 배포판의 패키지명을 확인하세요).

그런 다음 Firefox에서 미디어가 재생 중일 때 아래 명령을 실행합니다:
```bash
dbus-send --print-reply --dest=org.freedesktop.DBus /org/freedesktop/DBus org.freedesktop.DBus.ListNames|grep mpris
```
출력 결과에 다음 라인이 포함되어야 합니다:
```plain
string "org.mpris.MediaPlayer2.plasma-browser-integration"
```
오직 "plasma-browser-integration" 이름만 작동합니다. 다른 이름은 작동하지 않습니다.

어떤 이유로든 Firefox의 dbus에 `org.mpris.MediaPlayer2.plasma-browser-integration`이 나타나지 않는 경우 다음 단계를 시도해 보세요:
1. `firefox --ProfileManager`를 사용해 새 프로필을 생성합니다.
2. 새 프로필로 Firefox를 실행하고 Plasma Integration 확장 프로그램을 다시 설치합니다.
3. 새 프로필로 Firefox를 재시작하고 다시 시도합니다.
- _참고: 디버깅에는 `playerctl -F metadata` 명령도 유용할 수 있습니다._

## 아이콘 대신 이상한 아이콘 이름 텍스트가 표시됨
- Material Symbols 폰트(Material Icons가 아님)가 설치되어 있는지 확인하세요.
  - Arch Linux에서는 `ttf-material-symbols-variable-git` 패키지를 사용하세요.
  - 사용 중인 배포판에 해당 패키지가 없다면 수동으로 설치하세요:
    - [Material Symbols 리포지토리](https://github.com/google/material-design-icons/tree/master/variablefont)에서 .ttf 파일을 다운로드합니다.
    - 다운로드한 파일들을 `~/.local/share/fonts` 경로에 넣습니다.
    - `fc-cache -fv`로 폰트 캐시를 갱신합니다.
    - `Ctrl`+`Super`+`R`로 쉘을 재시작합니다.

## `loginctl lock-session`이 아무 작업도 하지 않음
> 참고: [end-4/dots-hyprland#278](https://github.com/end-4/dots-hyprland/issues/278)

[Arch Linux 포럼의 이 게시글](https://bbs.archlinux.org/viewtopic.php?pid=1311990#p1311990)에 따르면:
> 이 기능이 작동하려면 systemd-logind의 dbus 신호를 수신 대기하는 프로세스가 있어야 합니다.

Hypridle이 이 역할을 수행할 수 있으므로, Hypridle이 실행 중인지 확인해야 합니다.
Hypridle이 실행 중이면 `loginctl lock-session` 명령이 Hypridle에 신호를 보내고,
결과적으로 Hypridle은 설정 파일(`~/.config/hypr/hypridle.conf`)에 정의된 `$lock_cmd`를 실행하여 화면을 잠급니다.

자세한 내용은 [Hyprland Wiki](https://wiki.hypr.land/Hypr-Ecosystem/hypridle/#configuration)를 참고하세요.

## 사이드바 Wi-Fi 토글이 작동하지 않음
- `NetworkManager`가 설치되어 있는지 확인하세요. Arch 기반 배포판의 경우:
  ```bash
  sudo pacman -Q NetworkManager
  sudo pacman -S NetworkManager  # 설치되어 있지 않은 경우
  ```
- `NetworkManager` 서비스가 실행 중인지 확인하세요.
  ```bash
  sudo systemctl status NetworkManager
  # 실행 중이 아니라면 활성화 및 시작
  sudo systemctl enable NetworkManager
  sudo systemctl start NetworkManager
  ```
  변경 사항을 적용하려면 Quickshell을 재시작하세요.
- (사이드바 토글이 작동하지 않아) Wi-Fi 설정을 위해 어쩔 수 없이 다른 네트워크 관리자(예: `iwd`)를 사용하게 된 경우, 두 서비스가 충돌하지 않도록 `NetworkManager`가 `iwd`를 백엔드로 사용하도록 설정할 수 있습니다.
  - `NetworkManager` 백엔드 설정 파일 생성:
    ```bash
    sudo nano /etc/NetworkManager/conf.d/wifi_backend.conf
    ```
  - 파일 내부에 다음 내용 작성:
    ```ini
    [device]
    wifi.backend=iwd
    ```
  - 파일을 저장하고 Quickshell을 재시작하여 적용하세요.

# 설정 관련 질문

## 텔레그램 등 메시징 앱에서 새 메시지가 올 때 포커스를 빼앗지 않게 하려면 어떻게 하나요?
- Hyprland의 `misc:focus_on_activate` 변수를 `false`로 설정하세요.

## 애니메이션 관련 요소들을 비활성화하려면 어떻게 하나요?
- 설정 앱(`Super`+`I`)을 열고 General로 이동하여 "Weeb" 정책 항목에서 "No"를 선택하세요.

## AI 기능을 비활성화하거나 로컬 모델로만 제한하려면 어떻게 하나요?

설정 앱(`Super`+`I`)을 열고 General 섹션으로 이동하여 "AI" 정책을 변경하세요.

## 화면 테두리의 가짜 둥근 모서리를 제거하려면 어떻게 하나요?

설정 앱의 옵션 항목에 해당 기능이 있으니 탐색해 보세요.

## 터미널 색상의 가독성이 떨어집니다.

설정 앱의 "Advanced" 섹션으로 이동하여 Terminal Harmony 수치를 낮추세요.

## 빠른 프록시/VPN 설정이 있나요?
이용 제한 우회를 위해, Cloudflare Warp가 설치되어 있다면 쉘에서 빠른 토글 버튼을 제공합니다. 설정(Configuration) 페이지의 관련 섹션을 참고하세요.

[#1991](https://github.com/end-4/dots-hyprland/discussions/1991) 게시글을 참고하세요.
