## 개요 (Overview)

- `Super` 또는 `Super`+`Tab`으로 열기
- 창을 다른 워크스페이스로 드래그하여 이동
- 마우스 가운데 클릭(휠 클릭)으로 창 닫기

## 런처 (Launcher)

- 개요(Overview)와 번들로 제공됩니다. 그냥 키보드로 타이핑을 시작하세요.
- 검색 결과 포함 항목:
  - 앱 검색
  - 수학 계산 결과
  - [접두사: `/`] 런처 액션
  - [접두사: `;`] 클립보드 기록
  - [접두사: `:`] 이모지
  - 입력한 내용에 대한 추가 작업: 명령어 실행, 검색 수행

- 부연 설명이 필요한 런처 액션:
  - `/superpaste 개수[i]`: 최근 클립보드 항목 중 지정한 개수만큼 붙여넣기합니다. 이미지인 경우 `i`를 지정하세요.
  - `/todo 할일`: 할 일 목록에 항목 추가

## 상단 바 제어
- 미디어 위젯:
  - 휠 클릭: 재생/일시정지
  - 우클릭: 다음 트랙
  - 마우스 4번/5번 버튼: 이전/다음 트랙
- 밝기 조절: 좌측 상단 모서리에서 스크롤
- 음량 조절: 우측 상단 모서리에서 스크롤
- 워크스페이스:
  - 마우스 4번 버튼: 특별 워크스페이스(Special workspace) 토글
  - 우클릭: 개요(Overview) 열기

# 왼쪽 사이드바

## 일반 제어
- 인텔리전스 및 애니메이션 탭에서의 탭 자동 완성
  - 입력창 위에 추천 문구가 뜨면 위/아래 화살표 키로 선택하고 Tab 키를 눌러 확정합니다.
- 어시스턴트 창을 분리하고 싶으신가요? 사이드바를 별도 창으로 분리하려면 `Super`+`Alt`+`A`를 누르세요.

## AI 채팅

- `/model`을 입력하여 모델을 선택합니다. 로컬에 설치된 Ollama 모델은 자동으로 감지됩니다.
- `/key`를 입력하면 온라인 모델용 API 키를 구하는 방법이 안내됩니다.
- 현재 툴 기능이 지원되는 Gemini 모델은 쉘 설정을 수정할 수 있습니다. 예를 들어 "내 워크스페이스에서 앱 아이콘을 숨겨줘"라고 요청할 수 있습니다.

## 번역기

`trans` CLI 도구를 통해 처리됩니다. 특별히 설명할 내용은 없습니다...

## 애니메이션 보루 (Anime boorus)

- `/mode`를 입력하여 이용 가능한 제공자를 확인하세요.
- 1개 이상의 태그를 입력하여 결과를 확인하세요. 타이핑하는 동안 추천 태그가 표시됩니다.
- 숫자를 입력하여 조회할 결과 페이지를 선택하세요.

# 배경화면 및 색상
- 배경화면을 변경하려면 `Ctrl`+`Super`+`T`를 누르고 이미지를 선택하세요. 다음 작업이 함께 수행됩니다:
  - 쉘, Qt 앱, GTK 앱의 색상 변경
  - 배경 시계의 위치를 이미지에서 가장 덜 복잡한 영역으로 이동 (현재 단일 모니터에서 가장 잘 작동함)

# 스크린샷 도구

- `Super`+`Shift`+`S`: 화면 캡처 | 좌클릭 드래그로 클립보드 복사, 우클릭 드래그로 주석 달기
- `Super`+`Shift`+`A`: Google 렌즈 검색
- `Super`+`Shift`+`X`: 텍스트 인식 (OCR)

# 화면 번역

Google Cloud Vision 및 Translation API를 사용하여 화면 내용을 번역합니다. 이 섹션에서는 설정 과정을 안내합니다.

## 사전 준비

- Google 계정이 필요합니다.
- 정식 계정을 활성화하지 않는 한 요금이 청구되지 않지만, Google은 부정 사용 방지를 위해 신용/체크카드를 요구합니다. 잔액이 소액 남아있는 가상 카드도 정상적인 카드라면 사용 가능합니다.

## 설정 방법

- [Google Cloud Console](https://console.cloud.google.com/)에 접속하여 프로젝트를 생성하거나 선택합니다. 사이드바 채팅용으로 Gemini API 설정을 해두었다면 동일한 프로젝트를 사용해도 됩니다.
- 다음 API를 활성화하세요:
  - [Cloud Vision API](https://console.cloud.google.com/marketplace/product/google/vision.googleapis.com)
  - [Cloud Translation API](https://console.cloud.google.com/marketplace/product/google/translate.googleapis.com)
- 왼쪽 내비게이션 메뉴에서 **결제(Billing)** 섹션으로 이동합니다. **결제 계정 연결(Link a billing account)**을 누르고 필요한 정보를 입력합니다.
- 왼쪽 메뉴에서 **IAM 및 행정** > **서비스 계정**으로 이동합니다. **서비스 계정 생성**을 누른 후:
  - 1단계: 이름을 입력합니다. 아무 이름이나 입력해도 무방합니다.
  - 2단계: 권한 설정에서 **Service Usage Consumer** 및 **Cloud Translation API User** 역할을 추가하고 **계속**을 누릅니다.
  - 3단계: **완료**를 누릅니다.
- 이제 목록에 생성된 서비스 계정이 보입니다. 우측의 점 3개 메뉴를 누르고 **키 관리**를 선택합니다.
  - **키 추가** > **새 키 생성**을 클릭합니다.
  - JSON 키 유형(기본값)을 선택하고 **생성**을 누르면 JSON 파일이 다운로드됩니다.
- 다운로드한 JSON 파일을 열고 내용을 복사합니다.
- `Super`+`Shift`+`T`로 화면 번역기를 연 후:
  - 화면 하단의 Key 입력 버튼을 클릭합니다.
  - 복사한 JSON 내용을 붙여넣고 Enter를 누르면 번역이 시작됩니다.
- 키 정보가 키링에 안전하게 저장되었으므로 다운로드한 JSON 파일은 삭제하셔도 좋습니다.
  - 참고: 추후 해당 키를 다시 확인하려면 illogical-impulse Safe Storage 키링 항목을 조회해야 합니다.

# 워크스페이스 그룹

## 탐색 및 워크스페이스 관리

10개의 워크스페이스로 부족하다면 Hyprland 한계치까지 다음 워크스페이스 세트를 사용할 수 있습니다. 바의 워크스페이스 위젯을 오른쪽으로 스크롤하거나 단축키를 사용하여 새 그룹으로 전환할 수 있습니다.

단축키와 쉘 위젯은 포커스된 워크스페이스 그룹에서 자연스럽게 작동합니다. 워크스페이스 표시기나 개요에 표시되는 워크스페이스 개수를 변경하지 않는 한 추가 설정이 필요하지 않습니다.

- **그룹 내 워크스페이스 탐색 / 이동**: 표준 Hyprland 단축키가 적용됩니다.
  - **11-20 워크스페이스(그룹 2)**에 있는 경우 `Super` + `2` $\rightarrow$ **12번** 워크스페이스로 이동합니다.
  - **21-30 워크스페이스(그룹 3)**에 있는 경우 `Super` + `Alt` + `3`은 포커스된 창을 **23번** 워크스페이스로 조용히 이동합니다.

- **그룹 간 탐색**:
  - 인접한 워크스페이스 그룹으로 이동하려면 다음 Hyprland 단축키 추가를 고려해 보세요.
    ```ini title="~/.config/hypr/custom/keybinds.conf"
    hl.bind("SUPER + ALT + Z", hl.dsp.focus({ workspace = "r-10" }))
    hl.bind("SUPER + ALT + X", hl.dsp.focus({ workspace = "r+10" }))
    ```
- **개요(Overview)** 및 **워크스페이스 표시기**가 자동으로 적응하여 현재 워크스페이스 그룹에 해당하는 내용을 표시합니다.
  
:::tip
워크스페이스 탐색 단축키를 수정하거나 [더 많은 기능](https://wiki.hypr.land/Configuring/Dispatchers/)을 포함하고 싶다면, `hyprctl dispatch` 대신 `~/.config/hypr/hyprland/scripts/workspace_action.sh` 스크립트를 사용하세요. 활성 워크스페이스 ID를 기반으로 현재 워크스페이스 그룹을 파악하여 알맞은 워크스페이스로 명령을 보냅니다.
:::

## 다중 모니터 고려 사항

효율적인 다중 모니터 관리를 위해 다음 전략을 고려해 보세요:
- 주 모니터에는 그룹 1(1-10번 워크스페이스), 보조 모니터에는 그룹 2(11-20번 워크스페이스)를 할당:
  - 부팅 시 보조 모니터의 시작 워크스페이스를 `Super` + `0`을 누른 후 `Ctrl` + `Super` + `Right`를 사용하여 두 번째 그룹(예: 11번 워크스페이스)으로 수동 이동합니다.
  - 이렇게 하면 모니터별로 개별 개요 위젯이 생성되는 효과도 얻을 수 있습니다.
- [워크스페이스 바인딩 규칙](https://wiki.hypr.land/Configuring/Workspace-Rules/#rules)을 사용하여 특정 워크스페이스를 특정 모니터에 고정합니다. `hyprctl monitors | grep Monitor`를 실행하여 모니터 이름을 확인할 수 있습니다.
  ```ini title="~/.config/custom/general.conf"
  # 1-10번 워크스페이스(그룹 1)를 주 모니터에 바인딩
  for i = 1, 10 do
    hl.workspace_rule({ workspace = tostring(i), monitor = "eDP-1", default = true })
  end

  # 11-20번 워크스페이스(그룹 2)를 보조 모니터에 바인딩
  for i = 11, 20 do
    hl.workspace_rule({ workspace = tostring(i), monitor = "HDMI-A-1", default = true })
  end
  ```
- 각 모니터에서 한 번에 두 개의 워크스페이스에 집중하고 필요에 따라 모니터/그룹 간에 창을 이동/교체(`Super` + `방향키` 또는 `Super` + `Shift` + `방향키`)합니다.

:::note
워크스페이스 그룹 기능은 Hyprland나 다른 상태 바 시스템에서 자체 지원하는 기능이 아닙니다. 이 설정은 Hyprland 디스패처와 쉘 설정을 조합하여 해당 기능을 구현합니다.
:::
