# 설명
`windoes`, `hybrid`, `NovelKnock` 등을 포함한 여러 Eww 설정 모음입니다.

# 설치
- 의존성: 브랜치별 의존성 목록을 참고하세요.
- 다음 항목들을 복사하세요:
    - `.config`, `.local` 폴더를 홈 디렉토리로 복사
    - `.local/share/icons` 안의 폴더들을 `/usr/share/icons` 경로로 복사
    - 필요에 따라 `Import manually` 폴더 안의 항목들을 복사

 ## 권장 환경 및 성능
|  ⌄  | 권장 | 권장하지 않음 | 비고 |
| --- | ------ | ----------- | ------------------------- |
| 커널 |     | cachyos, xanmod | 절전 기능을 너무 남용하지 마세요. 개인적인 경험에 따른 의견일 뿐입니다. |
| 로그인 쉘  | bash/zsh | fish | 터미널 내에서 fish를 사용하는 것은 괜찮습니다. (end_4도 그렇게 사용 중입니다) |

 ## 설정 (Setup)
 - eww 설정은 `~/.config/eww` 경로에서만 정상 작동합니다.
 - `eww daemon` 명령어로 eww를 실행하세요.
 - 상단 바 열기: `eww open bar`
 - Windows 스타일 바 열기: `eww open winbar` (`windoes`/`hybrid` 브랜치)
 - 하단 라인 열기: `eww open bottomline` (화면 하단 테두리를 클릭했을 때 음악 창이 열리도록 설정)
 - 개요(Overview)를 열고(워크스페이스 중앙 클릭) 앱 검색 캐시가 생성될 때까지 10초간 기다리세요. (기다리지 않으면 아이콘이 올바르게 표시되지 않을 수 있습니다)

 ## 사용법
 - 음악 제어: 휠 클릭(마우스 가운데 클릭)으로 재생/일시정지, 우클릭으로 다음 트랙 이동, 스크롤하여 볼륨 조절
 - 개요(Overview)를 열려면 워크스페이스 표시기를 휠 클릭/우클릭하거나 `eww open overview`를 실행하세요.
 - 개요에서 검색어를 입력하여 앱을 검색할 수 있습니다 (자세한 내용은 아래 참고).

 ## 검색 기능
 - 앱 이름을 입력하여 검색
 - 수식을 입력하면(숫자로 시작해야 함) `qalc`를 사용하여 계산 수행
 - `>save 테마이름`: 현재 컬러 스킴을 입력한 '테마이름'으로 저장
 - `>load 테마이름`: 저장된 테마 불러오기 (입력하는 동안 사용 가능한 테마가 표시됨)
 - `>music`: 현재 재생 중인 미디어 썸네일에서 컬러 스킴 추출
 - `>wall`: `~/.config/eww/images/wallpaper/wallpaper` 경로의 배경화면에서 컬러 스킴 추출
 - `>light`: 다음 컬러 생성 시 라이트 모드를 사용하도록 설정
 - `>dark`: 다음 컬러 생성 시 다크 모드를 사용하도록 설정
 - `>one`: 다음 컬러 생성 시 바 아이콘에 단일 색상만 사용하도록 설정
 - `>multi`: 다음 컬러 생성 시 바 아이콘에 다양한 색상을 사용하도록 설정
 - `>r`: 새로고침 (eww를 종료하고 기본 바와 함께 다시 실행)
